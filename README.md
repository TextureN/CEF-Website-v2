# CEF Website v2

Public-facing website for Community Enterprise Fund (CEF).

## Current status
- Initial responsive homepage committed in `index.html`.
- No login or authentication is required for the public website.
- Built with HTML, CSS and JavaScript; no build step is required.

## Homepage sections
- Hero and introduction
- Development finance and enterprise services
- About CEF
- Programmes and delivery areas
- Implementation approach
- Contact call to action

## Preview locally
Open `index.html` in a modern browser.

## Deployment
The site can be published with GitHub Pages. The repository workflow in `.github/workflows/pages.yml` deploys the site when changes are pushed to `main`, once GitHub Pages is configured to use GitHub Actions.

## Before launch
Confirm official contact details, approved CEF logo and brand assets, public claims and statistics, privacy/legal notices, and the final domain. The current email link is a placeholder and should be verified before launch.
